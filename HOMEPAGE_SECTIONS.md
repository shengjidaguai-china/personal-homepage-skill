# Homepage Sections

Use this file to decide what each section should contain, how it should look, and what to avoid.

## Candidate Section Order

```text
Hero
About
Highlights
Skills
Projects
Experience
Content / Writing / Media
Testimonials
Contact
Footer
```

Homepage Mode only. Choose and reorder sections for the user’s goal; these are content guides, not mandatory page structure. Remove irrelevant sections. Do not fill with fluff. A portrait, secondary CTA and background motion are optional.

## 1. Hero

### Purpose

Make the visitor remember the person in 5 seconds.

### Useful ingredients

- name / nickname
- professional identity
- one-line value proposition
- avatar / 3D identity / abstract symbol
- primary CTA
- secondary CTA
- background motion or spatial layering

### Recommended layouts

- Cinematic Scroll Hero
- 3D Floating Avatar Hero
- Terminal Identity Hero
- Magazine Cover Hero
- Spatial Portfolio Hero
- Glass Card Hero
- Motion Gradient Hero
- AI System Hero

### Avoid

- plain SaaS hero
- generic left text, right stock image
- huge vague slogan without proof
- fake metrics
- unreadable background

## 2. About

### Purpose

Explain who the person is without writing a long autobiography.

### Content formula

```text
One positioning sentence.
One sentence about current direction.
One sentence about relevant past experience.
One sentence about personal style or edge.
Optional credibility sentence.
```

### Visual patterns

- split text + identity card
- editorial paragraph with margin notes
- mini profile card + three facts
- terminal `about.json`

### Avoid

- long self-introduction
- generic passion copy
- unsupported claims

## 3. Highlights

### Purpose

Show advantages, proof, or momentum quickly.

### Content examples

```text
3 years AI product exploration
12 project demos
20万+ content exposure
5 open-source tools
```

If not provided, use placeholders:

```text
待补充：项目数量
待补充：内容曝光
待补充：开源贡献
```

### Visual patterns

- bento cards
- stat strip
- orbiting badges
- editorial fact blocks

### Avoid

- invented numbers
- all cards same size
- metrics without context

## 4. Skills

### Purpose

Explain capability structure, not tool familiarity.

### Group examples

```text
AI / LLM
Frontend
Product
Design
Content
Research
Business
```

### Skill card formula

```text
Capability name
What this person can do
Related output / project / content
Tools as supporting detail
```

### Avoid

- icon wall
- only listing React / Python / Figma
- unrelated skill dumping

## 5. Projects

### Purpose

Provide the strongest proof of capability.

### Useful fields per project

```text
Project name
One-line description
Problem solved
My role
Core features
Tech stack
Result / highlight / placeholder
Link / placeholder
Screenshot placeholder
```

### Display patterns

- 3D Project Cards
- Bento Grid
- Case Study Cards
- Horizontal Scroll Gallery
- Interactive Mockup Cards
- Timeline Project Wall
- Code + Preview Split Layout

### Avoid

- identical cards
- project name + vague sentence only
- screenshots without explanation
- fake results

## 6. Experience

### Purpose

Show timeline and credibility without copying a resume table.

### Entry formula

```text
Time / organization / role
What I owned
Problem solved
Result or learning
Related project / proof
```

### Visual patterns

- milestone timeline
- role cards
- journey map
- log stream

### Avoid

- full resume table
- responsibilities without outcomes
- overlong paragraphs

## 7. Content / Writing / Media

### Purpose

Show creator output, thought leadership, or learning journey.

### Can include

- articles
- videos
- Xiaohongshu notes
- GitHub projects
- podcasts
- courses
- talks
- newsletter

### Visual patterns

- featured content cards
- topic tag cloud
- channel entry cards
- media wall

### Avoid

- empty section if user has no content
- fake platform links
- vanity metrics without source

## 8. Testimonials

### Purpose

Add trust if real endorsements exist.

### Use only if

- user provides real quotes
- user asks for placeholder testimonial section
- section is clearly marked as placeholder

### Avoid

- invented endorsements
- fake client names

## 9. Contact

### Purpose

Make the next action obvious.

### CTA examples

```text
Contact me
View projects
Download resume
Book a call
Follow my content
```

### Supported links

```text
email
GitHub
LinkedIn
X
Xiaohongshu
Bilibili
WeChat QR placeholder
personal blog
resume download
calendar booking
```

### Visual patterns

- premium CTA block
- contact card
- social link rail
- QR placeholder card

### Avoid

- burying contact in footer only
- broken links
- unclear CTA

## 10. Footer

### Purpose

Close the page cleanly and reinforce identity.

### Include

- short identity line
- copyright or year
- key links
- optional tech credit

### Avoid

- large unrelated sitemap
- generic template footer
