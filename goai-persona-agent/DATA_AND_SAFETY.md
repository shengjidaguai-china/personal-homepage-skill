# Data and Safety

- 演示档案经用户明确授权用于 GOAI 参赛开发；公司名称保持隐藏。
- 仓库不包含真实简历原文、手机号、邮箱、访问令牌、Cookie、私有来源快照或第三方账号凭据。
- `homepage-delivery-example.jpg` 来自用户指定的本地个人主页 Demo，只用于说明视觉交付能力。
- G2 前所有外部个人资料工具默认拒绝；授权只读、按用途和期限记录。
- 发布前必须通过 QA 与 G3 人工确认；撤回来源后，关联主张进入复核并触发回滚。
- 无 API Key 模式使用同一领域契约重放公开/授权案例；不得把它表述成真实模型或真实 AgentTeams 集群调用。
