# 16:9 HTML PPT starter

Copy [presentation.html](presentation.html) for a fixed 1920×1080 slide deck. Its two sample slides demonstrate structure, not a complete visual theme. Adapt the chosen style independently of homepage section layouts.

The file already embeds shared editing/export and PPT playback/presenter helpers. Use arrows, Space or PageUp/PageDown to navigate, Home/End for first/last, F for fullscreen, E for editing, Cmd/Ctrl+S to save and N for an independent presenter window. **导出 HTML** preserves edited text and notes and remains editable when reopened.

Keep stable slide and edit IDs. Add full notes using `data-note-for` outside the audience stage. Read [PPT workflow](../../PRESENTATION_WORKFLOW.md), [shared HTML capabilities](../../references/html-editing-export.md) and [presenter notes/sharing](../../references/presenter-mode.md). After helper source changes, re-run the bundler in `presentation` mode. Test structure, rendering and export before delivery.
